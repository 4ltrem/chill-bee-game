## Bugs and deviations

### BUG-1 (blocking) Dragging cannot uncap cells. Owner: Patricia, `game/scripts/honeycomb.gd` line 200
`get_viewport().get_camera_3D()` does not exist in Godot 4.2.1. The Viewport method is `get_camera_3d()` (lowercase d). The spec text repeats the wrong name ("get_viewport().get_camera_3D()" in Node paths for Bob), so fix the spec line too.
Reproduce: run the game, wait for a full hive (or run `play_loop.gd`), press Harvest, press the left mouse button and drag across the cells. Nothing uncaps; the debugger prints `Invalid call. Nonexistent function 'get_camera_3D' in base 'Window'. at: Honeycomb._probe (honeycomb.gd:200)` once per probe (62 times in one test run). The harvest cannot be completed by a real player, so stage 1 is blocked.
Not caught by `--headless --quit-after 300` because the error only fires on input. After the fix, `play_loop.gd` re-checks the drag (row 0 uncaps, other rows do not) with no edits needed.
Note: the Godot parser accepted the call; no static check flagged it.

### NOTE-1 (non-blocking) rcedit not configured for the Windows export. Owner: developer / export preset
The export warns that `rcedit` cannot run, so version info and product name are not written. Either set the path in Editor Settings (Export > Windows > rcedit) or turn off "Application > Modify Resources" in the preset.
