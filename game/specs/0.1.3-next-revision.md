# 0.1.3 Next revision (draft)

**Builds on** `game/specs/0.1.2-bottling-and-sale.md`. Process: `game/CONTEXT.md`. Not approved; nothing is built from it yet.

## Changes

1. **Game speed in Dev mode** (designer, 2026-11-05: "use the dev panel to speed up the time in the game, or speed up a certain animation, whichever is best").
   - **Choice: one game-speed control, not a per-animation one.** Every timed thing (bees, hive fill, lids, cell flights, crank, jars, truck) runs on the engine clock, so one `Engine.time_scale` speeds them all together and keeps their timing relative to each other, which is what a play-test judges. Speeding a single animation is already possible: its duration is a config value the panel edits (`lid_lift_seconds`, `jar_fly_seconds`, `bottling_seconds_per_jar` ...).
   - The panel already has ×1, ×2, ×5 buttons (`dev_panel.gd`, `_set_speed`). 0.1.3 makes them a full row: **×0.25, ×0.5, ×1, ×2, ×5, ×10**. Slow motion is for watching one animation closely (the pop, the lid lean, a jar's flight).
   - The current speed shows on the row (the active button is marked) and as a small "×N" tag in a screen corner while it isn't ×1, so a sped-up session is never mistaken for real pacing.
   - The speed resets to ×1 when the panel closes the game (as now) and on "Reset to defaults". It is never saved.
   - Every motion must follow the speed: no game code reads wall-clock time (`Time.get_ticks_*`, `OS` time) for gameplay or animation. Idle and offline earnings, when they come, will use wall-clock time on purpose and are excluded.
   - Hotkeys while Dev mode is on: `[` slower, `]` faster (one step along the row).
