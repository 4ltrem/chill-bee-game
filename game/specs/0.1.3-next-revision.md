# 0.1.3 Next revision (draft)

**Builds on** `game/specs/0.1.2-bottling-and-sale.md`. Process: `game/CONTEXT.md`. Not approved; nothing is built from it yet.

## Changes

1. **Game speed in Dev mode** (designer, 2026-11-05: "use the dev panel to speed up the time in the game, or speed up a certain animation, whichever is best").
   - **Choice: one game-speed control, not a per-animation one.** Every timed thing (bees, hive fill, lids, cell flights, crank, jars, truck) runs on the engine clock, so one `Engine.time_scale` speeds them all together and keeps their timing relative to each other, which is what a play-test judges. Speeding a single animation is already possible: its duration is a config value the panel edits (`lid_lift_seconds`, `jar_fly_seconds`, `bottling_seconds_per_jar` ...).
   - The panel already has ×1, ×2, ×5 buttons (`dev_panel.gd`, `_set_speed`). 0.1.3 makes them a full row: **×0.25, ×0.5, ×1, ×2, ×5, ×10, ×20** (designer, 2026-11-05: "add both"). Slow motion is for watching one animation closely (the pop, the lid lean, a jar's flight).
   - The current speed shows on the row (the active button is marked) and as a small "×N" tag in a screen corner while it isn't ×1, so a sped-up session is never mistaken for real pacing.
   - The speed resets to ×1 when the panel closes the game (as now) and on "Reset to defaults". It is never saved.
   - Every motion must follow the speed: no game code reads wall-clock time (`Time.get_ticks_*`, `OS` time) for gameplay or animation. Idle and offline earnings, when they come, will use wall-clock time on purpose and are excluded.
   - Hotkeys while Dev mode is on: `[` slower, `]` faster (one step along the seven-step row).

2. **Farm grid and camera** (designer, 2026-11-05; votes in `.claude/worktrees/ab-centrifuge/game/reports/round4-shots/decisions.json`, page https://claude.ai/artifact/17i3YsGsf9zD7NowGxtDSa).
   - 5 × 5 farm grid, Bob's layout C at cell size 2.0 (`game/specs/0.1.3-farm-grid-layouts.md`).
   - Round 4 pick: **C, bigger frames, rack c-1**: the whole hive scaled 1.4×, 7 × 5 cells kept (21.6 px at the round-4 zoom; closer is better).
   - **Camera rule (all zooms):** the first zoom always has the hive and the centrifuge in focus; the crate and the truck need not be visible. Zoom in closer than the round-4 shots (designer: "you can zoom in even closer").
   - **Second camera stop** (after the centrifuge is full): pans to the centrifuge, crate and truck, with the hive partly visible in the upper-right corner. The round-4 pan shot was voted no; this framing needs a new mock-up before the spec is approved.
   - STYLE_GUIDE V14 is now ≥ 20 px (designer, 2026-11-05); config `min_cell_px` becomes 20, which Quinn's `r4_measure.gd` reads.
   - Pending the GDD accept: crate tiers 1–3 (1, 2, 3 cells; each tier holds more jars waiting and makes a bigger truck load) and Deep Frame frames 2× longer (taking more of the screen). Terry's numbers wait until the upgrades and economy are defined (paths: `proposals/balance/harvest-upgrade-paths.md`).
