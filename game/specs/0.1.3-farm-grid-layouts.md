# 0.1.3 farm grid: three 5 x 5 layouts

Written proposal only. No scene, script or test was touched. Sources: `game/scenes/main.tscn`, `game/scenes/props/hive.tscn`, `game/reports/2026-11-05-0.1.2.md` (cell width 45.1 px at zoom size 2.4).

## 1. The format

`int[5][5]`, `grid[row][col]`, row 0 at the back (top of screen), col 0 at the left-back edge. Cell centre in the world: x = (col - 2) * cell, z = (row - 2) * cell. A multi-cell object repeats its code in every cell it covers.

| Code | Emoji | Meaning |
|---|---|---|
| 0 | ⬜ | empty |
| 1 | 🐝 | hive (1 cell) |
| 2 | 🌸 | flower patch (1 cell each, 3 in total) |
| 3 | 🌀 | centrifuge (1 cell) |
| 4 | 📦 | crate at tier 2 (2 cells) |
| 5 | 🚚 | truck (2 cells) |
| 6 | 🟡 | the pile of cappings (1 cell; the only extra thing that needs its own ground) |
| 7 | ➕ | the crate's tier-3 cell, kept free, in line with the crate |

Not coded, because they live inside the owner's cell: the hive lid spot (a marker 0.735 from the hive centre, inside the 1.5 cell) and the centrifuge lid spot (the lid tilts and leans against the centrifuge, reusing the hive lid's animation; designer, 2026-11-05), and the bees (flying, no ground).

Crate tiers: tier 1 = the one cell named per layout (half crate, 1.4 x 1.2 fits a 1.5 cell); tier 2 = that cell plus its neighbour in the row (the truck side) (today's 2.8 x 1.2 fits 3.0 x 1.5); tier 3 = the ➕ cell, in line with the other two (3 cells in a row; in B and C tier 1 is the middle cell, in A it is the end cell).

Portable shape (JSON, readable by a scene, GDScript or a future editor):

```json
{"cell_size": 1.5, "grid": [[0,0,0,0,0],[0,0,0,2,0],[2,0,1,3,2],[0,0,0,6,5],[0,7,4,4,5]]}
```
```gdscript
var d = JSON.parse_string(FileAccess.get_file_as_string("res://data/farm_a.json")); var pos = Vector3((col - 2) * d.cell_size, 0, (row - 2) * d.cell_size)
```

## 2. Rules and numbers

- **Cell size.** At 2.4 (ground 12) the diamond is 16.97 world units wide on screen; the portrait screen shows `size x 720/1280 = 0.5625 x size` across. Fitting it needs size about 12.6 x cell = 30 (more zoomed out, the opposite of the wish). So I propose **cell 1.5 (grid 7.5 x 7.5, ground mesh shrunk to match) and farm camera size 19** (12.6 x 1.5; edge objects sit at 2.83 x 1.5 = 4.24 from centre plus 1.06 half-footprint = 5.3, view half-width 19 x 0.5625 / 2 = 5.34). That is 5 percent closer than 20. Going closer needs a smaller cell (1.3 gives size 16.4, hive scaled to 0.9).
- **Hive** 1.4 box in a 1.5 cell: scale 1.0.
- **Centrifuge** for 1 cell: base diameter 2.2 to 1.4, **scale 0.64**.
- **Truck** 3.2 long into 2 cells (3.0): scale 0.93, long side along the row/column it occupies.
- **Crate** and **flowers**: unchanged sizes, they fit.
- Centrifuge: 1 cell, centre-to-centre 1 to 1.41 cells from the hive (edge or diagonal neighbour), 2 cells or less from the crate.
- Today's cell index (at 2.4): hive (r1.69,c1.54), centrifuge (r2.11,c2.32), pile (r1.89,c2.95), crate (r3.67,c2.0), truck (r3.75,c3.75), flowers (r1.79,c3.75), (r1.58,c0.33), (r0.75,c3.04).

## 4. Zoom B: does hive + centrifuge + crate fit at 44 px a cell?

Rack: frame bar outer 7.6 x 4.82 local, scaled 0.13, so 0.988 x 0.627 world; 7 x 5 cells. Measured at zoom size 2.4 (report 2026-11-05-0.1.2): 45.1 px a cell at 1280 / 2.4 = 533 px per screen unit, so one cell = 0.0846 screen units. (Cross-check: 0.988 x 0.707 view factor / 7 = 0.0998 pitch, 0.0846 is the cell itself, 85 percent of it.)

- Minimum scale for 44 px: 44 / 0.0846 = **520 px per screen unit**.
- Widest span at 44 px on 720 x 1280: width 720 / 520 = **1.38**, height 1280 / 520 = **2.46** screen units (camera size 2.46). With the optimistic pitch figure (441 px per unit) it would be 1.63 x 2.90.

Screen coordinates at cell 1.5: u (across) = 1.0607 x (dcol - drow); d (down) = 0.6124 x (dcol + drow).

| Layout | Centres (hive, centrifuge, crate tier 1) | u span | d span | Fits 1.38 x 2.46? |
|---|---|---|---|---|
| A | (2,2), (2,3), (4,3): u 0, +1.06, -1.06; d 0, 0.61, 1.84 | 2.12 | 1.84 | **No**, 0.74 too wide |
| B | (1,1), (2,2), (3,3): u 0, 0, 0; d 0, 1.22, 2.45 | 0 | 2.449 | **Centres only**, 0.01 spare |
| C | (1,2), (2,2), (3,3): u 0, -1.06, -1.06; d 0, 0.61, 1.84 | 1.06 | 1.84 | **Centres only**, 0.32 across, 0.62 down spare |

**Verdict: no layout fits whole objects.** The hive footprint alone is 1.4 x 1.414 = 1.98 across, over the 1.38 window, and the objects' heights and footprints add about 1.2 to the down span (B whole is about 3.6, C about 3.0). Only B and C fit their centres. **Closest option: Layout C**, framing the rack, the centrifuge crank and the near edge of the crate at once, with the hive walls and crate sides cropped, rack cells staying at 44 px or more. A whole-object zoom would need cells of about 30 px (B: 720 / 1.98 = 364 px per unit, 364 x 0.0846 = 31 px), which breaks the 44 px rule.
(Camera size 2.46 is only the horizontal-limit number; the framing marker would sit between the hive and the crate.)
