# Guide Characters
**Sources:** `GDD.md` (Story Premise & Onboarding: "a guide character (e.g., a queen bee; name and personality TBD)"), `content/onboarding-script.md` (v2 options), `content/onboarding-regression.md` (run 1 options), `content/biome-intros.md` (its options), `_meta/sessions/2026-10-31-fa5df4be/decisions.md` (D46).

Compiled by the orchestrator on 2026-11-07 from William's three drafts (designer: "the characters should be put in a separate file to make it easier to compare"). No line below is new: each comes from the draft named beside it. Empty slots are for William's signature-lines run.

**How the guides are used:** `onboarding-script.md` and `biome-intros.md` keep one shared script with `[GUIDE]` as the speaker. This file holds what differs per guide: name, personality, voice, and a signature line for each key moment. The build swaps in the chosen guide's name and signature lines (D46, widened 2026-11-07: all six stay until a playtest picks one).

## Decisions needed from the designer

Answered (designer, 2026-11-07): Pip is the scout bee; the sprite joins the playtest as its own guide, with Queen Maeve (six guides); Lady Aura is Dame Aura in French; William writes the signature lines; the GDD names the six candidates.

1. **The sprite's name** (EN and FR): proposed **Lumi** (*lumière*; reads the same in both languages; the pun in its welcome line needs it). Other options: **Glimmer** (EN) / **Lueur** (FR), or **Fizz** (works in both, but loses the light link).
2. **Queen Maeve in French:** proposed **Reine Maëve** (the Irish name with the diaeresis, as it is commonly spelled in Quebec French). The other option is plain **Reine Maeve**.
