# Operator obstacles, 2026-11-21 (0.2.1 build session)

Problems Oscar ran into while running the 0.2.1 build. Each is a candidate change to `.claude/agents/operator.md`, `operator/CONTEXT.md`, `operator/escalate.md` or an agent it dispatches. The changes themselves are an Opus/designer call (escalate.md: "changing a loop or a script's logic"); this is only the list.

Note: this session ran on Opus 5.5 (the designer ran `/model opus` before the request), so its token row is not a Sonnet operator data point for the Phase 5 comparison.

3. **No TaskStop.** (applied) Rex left a `tail -f` watcher and a backgrounded Godot run that neither he nor Oscar could stop.
