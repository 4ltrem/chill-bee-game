Chill Bee Game is the final project of a Multi-Agent AI for Game Development course. Approved 2026-11-04 in
`MILESTONES.md`: M1 0.1.x Harvest (spec `game/specs/0.1-harvest.md` + itch.io web export, 11/9), M2 A6 style guide
agent (GER loop over Bob's scenes, 11/12), M3 A5 goal-oriented coding agent (due 2026-11-15, target 11/14),
M4 0.2.x first automation built by the A5 agent (11/18), A7 pipeline + playable link + cost audit (~2026-11-19),
M5 0.3.0 course build (final ~2026-11-24). Prototype 0 is closed at revision 3. Versions are `0.<milestone>.<build>`.

**Why:** the GDD's first playable (full run) can't fit the course; the course needs a playable web link.

**How to apply:** check work against these dates; keep the final scope to harvest + first automation; A5/A6 are
built in this repo. Related: [[session-handoff]], [[usage-calibration]].
